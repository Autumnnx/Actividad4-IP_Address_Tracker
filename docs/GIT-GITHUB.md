# Git y GitHub

Ramas propuestas:

- `main`: versión estable.
- `develop`: integración del equipo.
- `feature/html`: estructura HTML.
- `feature/css`: estilos y responsive.
- `feature/javascript`: lógica de JavaScript, API e interacción.

Flujo: crear rama → trabajar → commit → push → Pull Request → revisión → merge.
